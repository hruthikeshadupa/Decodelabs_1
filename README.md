# Responsive Frontend Interface

A mobile-first responsive frontend based on the uploaded Full Stack Project 1 brief.

## Run
Open `index.html` in a browser.

## Files
- `index.html` — semantic page structure
- `styles.css` — responsive visual system and layouts
- `script.js` — mobile navigation and dynamic footer year

The interface follows the brief's themes: mobile-first design, semantic HTML, CSS Grid/Flexbox, accessibility-minded structure, wireframing/strategy, and the Mocha Mousse / Ethereal Blue / Moonlit Grey palette.
